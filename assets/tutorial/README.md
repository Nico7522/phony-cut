# Images du tutoriel de connexion

Captures d'écran d'un Xiaomi POCO X7 Pro (HyperOS, Android 16), en français,
affichées par l'assistant de connexion. JPG ou PNG, taille libre.

| Fichier | Écran | Étape de l'assistant |
| --- | --- | --- |

| `2.jpg` | Options pour les développeurs, interrupteur « Débogage USB » | 2. Débogage USB |

Ces images sont publiques (dépôt et installeur) : aucune information personnelle
(IMEI, numéro, nom personnel de l'appareil, notifications privées).
