## Nouveautés de la 0.2.0 / What's new in 0.2.0

- **Le son du téléphone** (Android 11 ou plus) : écouté sur le PC pendant l'aperçu,
  enregistré avec la vidéo, gardé dans les clips et joué dans « Mes clips ». Réglable dans
  Réglages > Son. / **The phone's sound** (Android 11 or later): heard on the PC during the
  preview, recorded with the video, kept in the clips and played in "My clips". Settings >
  Sound.
- Les enregistrements où le téléphone a tourné se lisent maintenant dans tous les lecteurs
  (cadre carré, finalisés en quelques secondes à l'arrêt). / Recordings where the phone
  rotated now play in every player (square frame, finished in a few seconds after the
  stop).
- L'export précis d'un clip contenant une rotation ne plante plus. / Precise export of a
  clip with a rotation no longer fails.
- L'installeur met à jour l'icône des raccourcis existants. / The installer refreshes the
  icon of existing shortcuts.

## Installer PhoneCut

1. Téléchargez **`PhoneCut-Setup-x64.exe`** ci-dessous.
2. Lancez-le. Aucun droit administrateur n'est demandé.
3. **Si Windows affiche « Windows a protégé votre ordinateur »** : cliquez sur
   **« Informations complémentaires »**, puis sur **« Exécuter quand même »**.
   Ce message apparaît parce que PhoneCut n'est pas encore signé numériquement ;
   il ne signale pas un problème dans le fichier.
4. Lancez PhoneCut depuis le menu Démarrer : un assistant vous guide pour
   brancher votre téléphone.

**Configuration requise :** Windows 10 ou 11 (64 bits), un téléphone Android 5.0
ou plus récent, un câble USB qui transfère des données.

## Install PhoneCut

1. Download **`PhoneCut-Setup-x64.exe`** below.
2. Run it. No administrator rights are needed.
3. **If Windows shows "Windows protected your PC"**: click **"More info"**, then
   **"Run anyway"**. This appears because PhoneCut is not digitally signed yet; it
   does not mean the file has a problem.
4. Start PhoneCut from the Start menu: an assistant helps you connect your phone.

**Requirements:** Windows 10 or 11 (64-bit), an Android 5.0 or newer phone, a USB cable
that transfers data.
